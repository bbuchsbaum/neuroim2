# A minimal, publication-friendly theme for image slices

Quiet axes, thin panel border, no grid, generous margins, slim legend.

## Usage

``` r
theme_neuro(base_size = 10, base_family = "", style = c("light", "dark"))
```

## Arguments

- base_size:

  Base font size.

- base_family:

  Base font family.

- style:

  Visual style, either `"light"` or `"dark"`.
