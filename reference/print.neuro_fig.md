# Print a device-fitted figure

Re-fits the arrangement of the already-built tiles to the current
device, then prints it like any patchwork.

## Usage

``` r
# S3 method for class 'neuro_fig'
print(x, ...)
```

## Arguments

- x:

  A figure returned by a `plot_*` function.

- ...:

  Passed to the patchwork print method.

## Value

`x`, invisibly.
